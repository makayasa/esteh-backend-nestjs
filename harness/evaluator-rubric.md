# Evaluator rubric

Nilai tiap dimensi 0 (gagal), 1 (sebagian), 2 (penuh), dengan rujukan bukti.

| Dimensi | Syarat nilai 2 |
| --- | --- |
| Correctness | Seluruh acceptance criteria scope yang diklaim selesai terbukti |
| Verification | Full gate + checks spesifik fitur berhasil, output tercatat |
| Scope | Sesuai plan, perluasan disetujui dan tercatat |
| Reliability | Rerun/restart/concurrency yang relevan terbukti; N/A beralasan |
| Maintainability | Batas module dan istilah bisnis sesuai plan/glosarium |
| Handoff | Progress + tracker + handoff cukup untuk melanjutkan sesi |

Accept: ≥10 dan tidak ada 0. Block: Verification=0 atau total ≤5.
Selain itu Revise. Skor tinggi tidak mengalahkan acceptance criterion yang
belum terpenuhi. Catat review pada progress baru, bukan mengubah bukti lama.
